# Sheriff Tornillo · Carrera en el Desierto

Portal web oficial del videojuego **Sheriff Tornillo**, un endless runner 3D western hecho en Unity 6.

- 🎮 Jugar: https://play.unity.com/en/games/3797a0b4-e17b-46d5-ab0b-ebe0cbc3c7af/sheriff-tornillo
- 👥 Autores: Juan Miguel Huanca Uruña · Axel Marcelo Canqui Ticona
- 🎓 Asignatura: Game Development · Univalle

## Tecnologías del sitio
- Bootstrap 5.3 y Bootstrap Icons
- AOS (animaciones al hacer scroll)
- Chart.js (gráficas)
- canvas-confetti y vanilla-tilt (efectos)
- HTML, CSS y JavaScript propios (`css/estilos.css`, `js/main.js`)

## Estructura
```
index.html
css/estilos.css
js/main.js
img/  (captura, personaje, og-image)
```
